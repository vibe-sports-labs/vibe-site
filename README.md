# Vibe Sports Landing

Landing pronta para GitHub Pages com domínio `vibesports.app`.

## Publicação
1. Crie um repositório, ex.: `vibesports-site`.
2. Suba estes arquivos para a raiz.
3. Settings > Pages > Deploy from a branch > `main` > `/ (root)`.
4. Custom domain: `vibesports.app`.
5. Configure o DNS do domínio.
6. Ative **Enforce HTTPS** quando disponível.
